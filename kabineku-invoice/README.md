# Kabineku manual invoice
Recovered from feat/invoice-kabineku-staging; mounted inside the final Purchasing Invoice module via a brand chooser. Noir source and official renderer are not replaced.
Kabineku is an opaque-origin sandbox without allow-same-origin: no parent DOM/CRM, Supabase credentials, business APIs, database writes, automatic numbering, or Noir localStorage access. Drafts are memory-only per tab. Export/import JSON is a user-controlled file backup, not a ledger. PDF assets are embedded in the bundle; CSP denies external/data API connections. Logo is still the earlier temporary vector reconstruction, not an official brand master.
Build: npm ci then npm run build here, then npm run build at repo root. Tests: node kabineku-invoice/node_modules/vitest/vitest.mjs run kabineku-invoice/tests from repo root.
